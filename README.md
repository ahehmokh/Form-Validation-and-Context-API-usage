# Job Application Request Form

A responsive job application form built with **React.js** to practice state management, Context API, form handling, conditional rendering, and reusable components.

The project simulates a simple job application submission flow where users can enter their personal information, employment status, and salary expectations.


##  GitHub Repository

https://github.com/ahehmokh/Form-Validation-and-Context-API-usage


##  Technologies Used

- React.js
- JavaScript (ES6+)
- React Context API
- React Hooks
  - `useState`
  - `useContext`
- HTML5
- CSS3

---

##  Features

- Responsive job application form
- Controlled form inputs
- Form validation using HTML5
- Age validation
- Email validation
- Conditional rendering for current salary
- Employment status checkbox
- Expected salary selection
- Form submission handling
- Success/confirmation screen
- Ability to submit another request
- Form reset after submission
- Animated confirmation screen
- Global state management using React Context API


##  React Concepts Practiced

### Context API

The project uses React Context API to share form data and UI state between components without passing props through multiple levels.

The Context manages:

- Form data
- Form visibility
- Confirmation visibility
- Form reset functionality
